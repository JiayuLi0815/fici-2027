# 2027 第二十四届中国文化产业新年论坛 · 官网

静态站点，无构建步骤，双击 `index.html` 即可查看（也可 `python3 -m http.server` 起本地服务）。

## 文件

```
index.html          首页（全部板块）
detail.html         论坛板块详情页，?t=板块名 切换标题
assets/style.css    全部样式
assets/main.js      导航、倒计时、滚动高亮、入场动画
assets/hero-poster.png  主视觉海报（当前为设计稿）
```

## 板块结构

导航参照历年新年论坛专题站的栏目划分，视觉参照北京文化论坛 2026 官网：

论坛简介 / 最新消息 / 简要日程 / 论坛板块 / 演讲集萃 / 出版物 / 论坛风采 / 历届论坛 / 参会服务

## 配色

取自 `assets/hero-poster.png`，变量集中在 `style.css` 顶部 `:root`：

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--cream` | `#FFF9ED` | 页面底色 |
| `--crimson` | `#AB2848` | 主色（标题、主按钮、信息条） |
| `--peri` / `--peri-ink` | `#738EFF` / `#4553C4` | 辅助色（小标题、链接） |
| `--yellow` | `#FFD839` | 点缀 |
| `--coral` | `#FF737A` | 点缀 |

## 替换内容时注意

- 所有板块目前填的是占位文案，直接替换文字即可，无需改结构。
- 图片位目前是渐变占位块，换成 `<img>` 时保持外层 class，宽高比会被沿用。
- 历届论坛的年份与链接已按官方站核对；第二十二、二十三届暂无专题页。
